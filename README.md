
# SeatSync – Smart Library Seating System

## About
SeatSync is a frontend-based smart library seating platform designed to help students find and reserve library seats conveniently.

## Problem
Students often waste time searching for available seats in crowded college libraries.

## Solution
SeatSync provides an interactive seating map that allows students to explore floors, check seat availability and make demo reservations.

## Features
- Interactive seating map
- Three library floors
- Study zone filters
- Seat reservation system
- Booking confirmation
- My Bookings dashboard
- Reservation cancellation
- Dark and light themes
- LocalStorage data persistence
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage
- Font Awesome

## Installation
1. Download or clone this repository.
2. Open the SeatSync folder.
3. Open index.html in your browser.

## Important Note
This is a frontend-only prototype. Seat availability is simulated, and bookings are stored locally in the browser. It does not connect to actual library sensors or a central reservation server.
